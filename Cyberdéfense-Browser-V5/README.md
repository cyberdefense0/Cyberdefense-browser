# Cyberdéfense Browser

Prototype Electron browser with a cyberpunk security panel.

## Features

- URL bar + WebView browsing
- Basic tab-style header
- Cyber defense panel with HTTPS, tracker count, server country, technologies, domain score
- Live console log
- Neon/cyberpunk style with Tailwind and custom CSS

## Installation

1. Open a terminal in the project directory.
2. Run `npm install`.
3. Run `npm start`.

## Notes

- This is a version 1 prototype for a desktop browser shell.
- The VPN feature now uses app-level proxy routing to send browser traffic through selected country proxies.
- Future improvements can include phishing detection, SSL scanning, OSINT tools, terminal, and AI analysis.
